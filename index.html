연주실

건반을 누르고, 감정 코드 위에서 즉흥으로 작곡하고, 모둠이 밴드로 합주하고, 이야기로 곡을 짓고, 내 악기의 계이름을 확인하는 곳. 태블릿이나 노트북 하나면 됩니다.

학생 입장

선생님 초대 링크로 들어왔어요. 이름을 적으면 제출과 수업 상황이 선생님께 전달돼요.

🎹

건반실 Keyboard

코드 이름을 넣으면 눌러야 할 건반이 켜져요. 원하는 키로 옮기고, 4비트·아르페지오·왈츠 반주를 켜고 꾹 누르면 반주가 나와요. 한 마디를 2박·1박으로 나눠 코드를 넣을 수도 있어요.

코드 → 건반 점등키 변경리듬 반주피아노·신디·스트링·브라스
코드 반주를 처음 배울 때 · 프로덕션 넘버의 코드 연습
👫

짝꿍 피아노실 Duet Piano

위 건반은 멜로디, 아래 건반은 화음. 둘이 같은 1234 박자선을 보며 한 곡을 함께 쳐요. 계이름 블록으로 악보를 읽고, 기다려 주기를 켜면 칠 때까지 기다려 줘요. 멜로디를 비우면 코드 진행을 박에 맞춰 짚는 혼자 연습이 돼요.

멜로디·화음 2중주계이름 블록 악보16분음표·세 옥타브두 태블릿 합주곡 서랍 공유
피아노 2중주 · 코드 진행 연습 · 건반 파트 개인 연습
🎸

즉흥 작곡실 Jam

즉흥연주를 통한 작곡 — 감정에 맞는 코드 위에서 내 멜로디를. 기분을 고르면 요즘 노래 느낌의 코드가 정해지고, 건반 색으로 코드 음·분위기 음을 익힌 뒤 카운트인에 맞춰 마디나 구절 단위로 녹음해요. 악보와 MIDI로 남기고 반 친구와 나눠요.

기분별 코드 3종마디·구절 녹음앞당김·16분 격자악보·MIDI반 제출·친구 곡 듣기
즉흥 연주 · 화성 안에서 멜로디 만들기
🥁

밴드실 Band Room

팀을 짜고 악기를 나눠 받은 뒤, 곡의 코드를 정하고 내 악기 운지법으로 개인 연습 → 음원·마이너스 원 연습 → 지휘자 화면을 보며 다같이 합주해요.

6단계 밴드 수업기타·베이스·피아노 운지악보 사진 → 코드마이너스 원합주 화면·체크리스트
밴드 합주 수업 · 모둠 활동
🎼

이야기 작곡실 Composer

이야기를 통한 작곡 — 이야기를 처음·가운데·끝 세 장면으로 나누고, 장면의 감정이 곡의 조와 형식이 돼요. 4박 동기를 만들어(건반·녹음·AI) 반복과 변주로 12마디 곡으로 키우고, 마디마다 이야기의 순간을 적어요. 스타일·악기를 입히고 악보·MIDI로 남기고 반에 제출.

이야기 → 3장면장면별 감정·조동기 → 12마디4가지 변주악보·MIDIAI 질문·노래
작곡 첫걸음 · 변주 개념 · 표현과 성찰
🥁

리듬실 Rhythm

블록을 찍어 리듬과 코드를 만들면 신코페이션이 보라색으로 보여요. 만든 리듬을 내 파트로 박자에 맞춰 쳐보는 게임, 그리고 계이름·장단조·코드 종류·리듬을 귀로 맞히는 듣기 퀴즈.

리듬 블록신코페이션 표시박자 맞혀 치기듣기 퀴즈 4종진짜 드럼 소리
리듬 감각 · 귀 훈련 · 게임
🎼

솔페지오실 Solfege

시창·청음·초견·건반화성을 한 곳에서. 처음 보는 4마디 악보를 박에 맞춰 읽고 연주해요. 악기·조·난이도를 고르면 매번 새 악보가 나오고, 음정과 박을 바로 채점해 줍니다. 화음 초견과 음정 듣고 맞히기(완전4도·증4도…)도 함께.

선율 초견화음 초견음정 청음난이도 5단계연습지 인쇄
시창·청음·초견 수업 · 밴드 파트 연습
🎺

관악실 Wind

원곡 계이름을 넣으면(또는 악보 사진을 올리면) 트럼펫·클라리넷·색소폰·호른이 각자 불어야 할 계이름으로 바꿔 크게 보여주고, 그 악기 소리로 박자에 맞춰 흘려줘요. 전 악기 가이드를 한 장으로 인쇄.

실시간 이조B♭ · E♭ · F 악기악보 사진 → 계이름트럼펫 밸브파트별 가이드 인쇄
관악부 · 이조 악기 이해
